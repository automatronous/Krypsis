# Development

Requirements: Node.js 20+, npm, and Chromium for manual loading. Run `npm install --cache .npm-cache`, `npm run typecheck`, `npm test`, and `npm run build`. Load `dist/extension` from `chrome://extensions` with Developer mode and Load unpacked. Run `npm run serve:test-site` to open the synthetic pages. `npm run setup:model` only records the model gate; it does not download assets.
